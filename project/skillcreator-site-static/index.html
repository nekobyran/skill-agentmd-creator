01 / PRINCIPLE

不是又一个 Markdown 文本框

规则有结构，
文档仍是文档。

结构化编辑不该以抹平原文为代价。SkillCreator 只管理你明确交给它的字段， 未识别章节、嵌套 Markdown、代码块与自定义 frontmatter 都留在原位。

02 / CAPABILITIES

从规则骨架到可读文件

真实产品能力沿一条连续的编辑轨道展开，不把创作、审阅和落盘拆成相互失联的页面。

03 / WORKFLOW

把修改过程摆到台面上

选择、整理、审阅、落盘。

  1. 01

    选择结构

    从 Skill、规则类型或领域预设开始，先确定骨架。

  2. 02

    整理规则

    用名称、分类、触发与限制条件组织可维护单元。

  3. 03

    审阅提案

    逐项比较差异；提案停留在内存，等待明确决定。

  4. 04

    确认落盘

    确认后写入标准 SKILL.md，未识别内容保持不动。
